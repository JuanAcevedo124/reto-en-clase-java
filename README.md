# Filtro y ordenamiento de productos en Java

Ejercicio que filtra productos por categoría y los ordena por precio descendente usando expresiones lambda.

## Ejecución

```bash
javac *.java
java Main Electronica
```

Si no se indica una categoría, el programa la solicita por consola.
